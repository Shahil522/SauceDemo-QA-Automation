# SauceDemo QA Automation ## Project Summary

This project contains the manual testing documentation and the Selenium WebDriver automation for the SauceDemo e-commerce application.

## Tools Used
- Python
- Selenium Web Driver
- PyTest
- Google Chrome
- Visual Studio Code
- Git & GitHub 

### Automated test cases

The automation includes three primary user flows:

1. User login success
2. Add to cart and checkout
3. Lockout user login and error message check
